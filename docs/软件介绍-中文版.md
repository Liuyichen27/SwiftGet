## 软件介绍

SwiftGet 是一个轻量的 Windows 软件批量下载与安装工具。它把"找官网、下安装包、点下一步"这套重复流程压缩成一次勾选：在卡片列表里选中需要的软件，指定保存位置，点击开始，程序会自动挑选可用下载源、多线程加速下载、校验文件完整性，并在下载完成后静默安装。

下载内核采用开源的 aria2，直链下载支持 16 线程分片加速；同时内置 BitTorrent 支持，可以粘贴磁力链或导入种子文件，通过 DHT 网络从多个节点并行获取。程序为单文件绿色发布，内嵌全部运行组件，无需额外安装 Python 或运行库，双击即用。

软件清单内置 12 款常用工具，覆盖浏览器、社交办公、安全防护、系统工具与影音播放五类。清单支持本地编辑与远程更新，即便某个官方下载地址随版本变化，也可以在不重新打包的情况下修正。

## 主要功能

**1. 常用软件一键批量下载**
内置 12 款常用软件，卡片式勾选，支持分类筛选与全选/清空，一次可提交多个任务并行下载。

**2. 双引擎加速**
- 直链下载：多线程分片并发，默认 16 连接，服务器支持 Range 时提速明显。
- BitTorrent：支持磁力链与 `.torrent` 种子文件，通过 DHT + Peer Exchange 从多节点并行拉取。

**3. 多源自动切换**
每款软件配置多个下载地址，下载前自动预检可用性并择优使用；单一源失效不影响整体流程。

**4. 静默安装**
对支持静默参数的安装包，下载完成后自动在后台完成安装，全程无需手动点击。仅首次安装时弹出一次系统管理员授权。

**5. 安装语言可选**
对支持语言参数的安装包（如 VLC），可指定简体中文或英文安装界面；其余安装包自动跟随系统语言，界面会明确提示。

**6. 实时进度反馈**
每张软件卡片内显示下载进度、已完成大小、实时速度、并发线程数与节点数量，完成后显示结果状态。

**7. 清单可维护**
内置清单支持导出为 JSON 手动编辑，也可配置远程清单地址在线更新，链接失效无需重新打包。

**8. 绿色单文件**
无需安装、不写注册表（仅保存用户配置于 %APPDATA%），删除即完全卸载。

## 使用说明

1. 双击 `SwiftGet.exe` 启动，无需安装。
2. 在「常用软件」页勾选需要的软件，可切换分类筛选。
3. 设置保存路径（默认 `用户目录\Downloads\SwiftGet`）与安装语言。
4. 点击「开始下载」，程序自动完成源预检、下载与安装。
5. 首次执行安装时会弹出系统管理员授权，点击"是"即可，程序本身以普通权限运行。
6. 需要下载其他链接时，切换到「链接 / P2P 加速」页，粘贴直链或磁力链，或选择种子文件。

## 技术说明

- 开发语言：Python 3.13
- 界面框架：CustomTkinter
- 下载内核：aria2 1.37（内嵌，JSON-RPC 控制）
- 打包方式：PyInstaller 单文件封装，附带 Per-Monitor DPI 清单
- 权限模型：默认普通权限运行，仅在执行安装时按需提权

## 注意事项

- 本软件仅提供下载与安装流程的自动化，所有安装包均直接来自软件官方或公开镜像地址，不经过任何中转服务器，也不修改安装包内容。
- 请在遵守各软件许可协议的前提下使用。
- 程序运行需要 .NET 之外的零额外依赖，但安装软件本身需要管理员权限。
- 部分软件的官方下载地址会随版本更新而变化，若遇到"所有下载源不可用"，可通过「设置 → 高级 → 导出清单」编辑后修复，或配置远程清单地址。
