## SwiftGet 1.0.0

第一个正式版本。一个简洁、开源、全自动的 Windows 软件下载器：勾选常用软件 → 选路径和语言 → 后台静默下载并安装。

### 亮点

- **常用软件一键静默安装**：内置 12 款高频软件，9 款可全静默装完，3 款（WPS / 360 / Bandizip）因安装器强制显示界面，会自动弹出向导代替静默
- **双引擎加速**：直链走 aria2 多线程分片（默认 16 连接），磁力链 / 种子走 BitTorrent + DHT
- **多源自动切换**：每个软件配置多个下载源，下载前预检，自动选可用源
- **清单可热更新**：远程 JSON 清单 + 本地覆盖，链接失效不用重新打包
- **单文件 exe**：内嵌 aria2 内核，24 MB，无需安装运行库，无需 Python 环境
- **Per-Monitor V2 DPI**：高分屏 / 多显示器下界面不糊不缩

### 使用提示

1. 首次安装软件时会弹一次 UAC 授权，点「是」——程序本身以普通权限运行，只在真正安装时提权。
2. 卡片上标注「需手动确认安装」的软件，安装阶段会自动把向导窗口弹到前台，点几下即可。
3. 安装包全部直连官方 / 公开镜像，不经过任何中转服务器。

### 已知限制

- 部分官方安装器不提供静默参数（WPS、360、Bandizip），无法做到零点击
- 安装语言只对支持 `/L=<LCID>` 的安装包生效（目前是 VLC）
- PyInstaller 打包的 exe 可能被杀软启发式引擎误报，源码完全开源可自行审阅重打包
